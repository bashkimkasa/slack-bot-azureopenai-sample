U07QPMVKE9X: Hi there, <@U0726LBFNF4>  At GoTo, Kubernetes (K8s) is utilized for managing containerized applications across clusters. The configuration of these clusters is often crowd-sourced, allowing external teams to contribute by creating namespaces, managing access, and adding labels and annotations for notifications and features like Istio sidecar injection <https://confluence.ops.expertcity.com/pages/viewpage.action?pageId=219858288|[1]>.  When a new team wants to deploy applications, they create a pull request in the designated repository, which, upon approval, leads to the creation of a new Helm chart artifact <https://confluence.ops.expertcity.com/pages/viewpage.action?pageId=219858288|[1]>. This process is streamlined to ensure efficient integration into the existing infrastructure.  Access to Kubernetes clusters is facilitated through a self-written controller called "k8s-sat2vault," which synchronizes Kubernetes ServiceAccount tokens into Vault for use by tools like fJive Jenkins <https://confluence.ops.expertcity.com/pages/viewpage.action?pageId=282646808|[3]>. Teams must annotate their namespaces to reflect their group names in Vault and create service accounts with the necessary permissions <https://confluence.ops.expertcity.com/pages/viewpage.action?pageId=282646808|[3]>.  Security is a priority, with specific protocols for managing certificates and permissions. The platform supports various AWS regions for deployment, ensuring flexibility and scalability . Overall, GoTo's Kubernetes implementation emphasizes collaboration, security, and efficient resource management.
